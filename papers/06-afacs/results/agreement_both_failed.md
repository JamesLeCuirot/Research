# Agreement on traces both coders judged failed (post hoc)

Computed for the journal version (4 November 2026) after an independent check noted that layer agreement over all 250 traces is inflated by traces at least one coder judged failure-free, where every layer is absent for both. Same measures and bootstrap as `afacs-agreement`, restricted to traces with `failure_observed = yes` from both coders. L1 cannot be computed: every failure has an L1 code.
